# MASM Projects

A collection of my MASM projects, examples, and articles, including projects originally developed with RadASM around 2008.

I'm revisiting these projects and gradually updating them for **Easy Code and MASM64 (x64)**. Both the original sources and the updated versions will be kept here to preserve their history and make the changes easy to follow.

## Projects

- **XM Music** — Embedding and playing XM music in a Windows application.
- **Animated Windows** — Window animations and fade-out effects.
- **ASCII to Hex** — Converting ASCII input to hexadecimal.
- **CreateProcess** — Launching a process using the Windows API.
- **Loader** — Modifying a program in memory while it is running.
- **Auto Sniffer** — Attaching to a running process and inspecting CPU registers.

Updates and x64 ports will be added as they are completed.
